# Miner

The miner is the mining job: mine stone and ores for job XP and Pounds.

## How do you earn XP?

| Block | Job XP |
|---|---|
| Stone | 0.78 |
| Deep slate | 1.4 |
| Coal | 2.5 |
| Nether Quartz | 2.0 |
| Lapis | 4.2 |
| Redstone | 4.4 |
| Iron | 4.0 |
| Gold | 4.8 |
| Obsidian | 7.0 |
| Emerald | 9.0 |
| Diamond | 12.0 |
| Old rubble | 24.0 |

## Skills

Unlockable via enchantments:

- **Drill**, **Vein Mining** (vein mining), **Smelt Touch** (ores directly to ingots), **Magnet** (collect drops).
