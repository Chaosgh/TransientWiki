Here's how to start and manage a cult.

## Start a cult

Each player can create their own cult. This is the first step to gain access to the bank, leveling system and factions.

**Command:** `/kult create <name> <tag>`
* **Name:** The full name of your cult (e.g. "The Watchers").
* **Tag:** A short abbreviation (3-4 characters) that is displayed in the chat (e.g. "WAKE").

## Important commands

| command | Description |
| :--- | :--- |
| `/kult invite <player>` | Invites a player into your cult. |
| `/kult accept` | Accepts a cult invitation. |
| `/kult kick <player>` | Removes a player from the cult. |
| `/kult leave` | Leaves the current cult. |
| `/kult chat <message>` | Sends a message only to cult members. |
| `/kult setmotd <message>` | Sets the "message of the day" that is displayed upon login. |
| `/kult donate <amount>` | Donate Pounds to the cult treasury, which convert into rubies for leveling up. |
| `/kult menu` | Opens the cult's main menu. |

## Settings

In the cult menu (`/kult`) you can make various settings:
* **Description:** Change your cult's public description.
* **Tag Color:** Choose a color for your iconic tag (unlocked through level).
* **Visibility:** Set whether your cult should be publicly listed.

<div class="md-note">
    <strong>Tip:</strong> Use <code>@kult</code> or <code>@clan</code> before your chat message to quickly write to the cult chat! (unlocked at level 4)
</div>
