Citybuild gives you your own plot on the server. Claim your land, build a home and shape it however you like.

## Plots

In Citybuild, each player gets their own **plot** - a demarcated piece of land on which only you (and invited players) can build and change.

Important plot commands:

| command | Function |
|---|---|
| `/plot auto` | Automatically assign a free plot |
| `/plot claim` | Claim the plot you stand on |
| `/plot home` | Teleport to your plot |
| `/plot add <player>` | Invite players to build (possible offline for you) |
| `/plot trust <player>` | Add players as fully trusted |
| `/plot remove <player>` | Remove players from plot |
| `/plot info` | Show information about the current plot |
| `/plot merge` | Merge two adjacent plots |
| `/plot clear` | Reset plot completely |
| `/plot delete` | Delete and share plot |
