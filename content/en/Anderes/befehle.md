The most important commands on TransientRealm. Dedicated pages list the job and cult commands.

## Teleport & Home

| command | Description |
|---|---|
| `/spawn` | Teleport to spawn |
| `/warp <name>` | Teleport to a warp |
| `/farmwelt` | Teleport to the Resource World |
| `/tpa <player>` | Send a teleport request to a player |
| `/tpaccept` | Accept a teleport request |
| `/tpdeny` | Reject a teleport request |
| `/tpahere <player>` | Requests for a player to teleport to you |
| `/sethome` | Setting a Home |
| `/home` | Teleport to a Home |
| `/homes` | List your home |
| `/delhome` | Delete a Home |

## Communication

| command | Description |
|---|---|
| `/msg <player>` (`/w`, `/tell`) | Send Private Message |
| `/r` | Reply to last private message |
| `/report <player>` (`/melden`) | Report a player |
| `/discord` (`/dc`) | Show Discord link |
| `/vote` | View Vote Links |

## Economy

| command | Description |
|---|---|
| `/pay <player> <amount>` | Pay Pounds to a player |
| `/pfund` | View your pound balance |
| `/store` (`/shop`) | Open the store |

## Plots (Citybuild)

| command | Description |
|---|---|
| `/plot auto` | Automatically assign a free plot |
| `/plot claim` | Claim the plot you stand on |
| `/plot home` | Teleport to your plot |
| `/plot add <player>` | Invite players to build |
| `/plot trust <player>` | Giving players full access to the plot |
| `/plot remove <player>` | Remove players from plot |
| `/plot info` | Show information about the current plot |
| `/plot merge` | Merge two adjacent plots |
| `/plot clear` | Reset plot completely |
| `/plot delete` | Delete and share plot |

## Chest shops

| command | Description |
|---|---|
| `/trustshop <player>` | Give/remove player access to the shop container |
| `/shareincome <player> <percentage>` | Share revenue with a player as a percentage |
| `/shopinfo` | View information about a store |

## Other

| command | Description |
|---|---|
| `/playtime` (`/spielzeit`) | View your playing time |
| `/enderchest` (`/ec`) | Open your ender chest |
| `/fly` | Toggle flight mode (where permitted) |
| `/hat` | Wearing an item as a hat |
| `/skull` (`/kopf`) | Obtain a player head |
| `/rename` | Rename an item |
| `/skipnight` | Vote to skip the night |
| `/settings` (`/einstellungen`) | Open player settings |
| `/wiki` | Open this wiki |

<div class="md-note">The team has additional moderation and management commands not listed here.</div>
