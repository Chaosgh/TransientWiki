Add other players as friends, level up your friendship together and unlock special features.

## Commands

| command | Function |
|---|---|
| `/friend` (`/freunde`) | Opens the Friends menu |
| `/friend add <player>` | Send friend request |
| `/friend accept [player]` | Accept request |
| `/friend deny [player]` | Reject request |
| `/friend requests` | View open requests |

You **end** a friendship via the menu: click on friend → *end friendship* → confirm.

## Friendship Level

Each friendship has a common **Level (1-10)** and gains experience:

- Completing **Friend Quests** gives XP.
- Writing a **private message** to a friend gives some XP (with anti-farm cooldown).

## Friend Quests

- You have **2 active quests** assigned at the same time, randomly assigned.
- Types: kill mobs together, mine blocks or defeat each other X times. Killing/mining only counts if a friend is **nearby (25 blocks)**.
- In the quest menu you can see the progress. **Shift + left click** skips a quest (then longer wait for the next one).

## Features by level

| Level | Feature |
|---|---|
| 1 | **Joint Account** — Deposit/Withdraw Pounds with `/freunde konto <einzahlen\|auszahlen\|check> <friend> [amount]` |
| 2 | **Death Ping** — when you die, friends get your coordinates |

You unlock further features with a higher friendship level.

## More features

- **Notes** for each friend (set in menu).
- **Online notifications** when a friend goes online or offline.
- **Statistics & Ranking** of your friendships.
