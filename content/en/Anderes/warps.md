# Warps

Warps are teleportation points that can be created and named by players themselves.

## Create a warp

Each player can create their own warps. A warp costs **3,500 Pounds** and is then visible and usable to all players via `/warp`.

| command | Description |
| :--- | :--- |
| `/spawn` | Teleports you to spawn |
| `/warp` | Opens the list of all available player warps |
| `/warp <name>` | Teleports you directly to a specific warp |

## Ranks

Certain promotions and benefits are tied to **player ranks**. Ranks can only be purchased in the official shop: [store.transientrealm.de](https://store.transientrealm.de)
