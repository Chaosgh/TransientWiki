The Resource World is a separate world where you can build farms and mine resources without restrictions. Unlike in the main world, everything here can be dismantled and changed.

## Versions

There are three variants of the resource world:

* **Normal** – The classic overworld farming world. Always available.
* **Nether** - The Nether farming world for Nether resources. Always available.
* **End** – The end farming world. Open only **Sundays and Wednesdays** — all day.

## Access

| command | Description |
| :--- | :--- |
| `/farmwelt` | Opens the resource world menu to select the version |

<div class="md-note">
    <strong>Note:</strong> The resource world is reset monthly. Do not store important items or buildings there permanently - they will be lost during the reset.
</div>

<div class="md-note">
    <strong>Griefing:</strong> In the farming world, relaxed rules apply - naturally generated blocks and structures can be dismantled. However, other players' farms and buildings may not be destroyed.
</div>
