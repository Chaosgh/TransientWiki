# Vote

By voting for TransientRealm on server lists, you support the server and receive **Votecoins** that you can exchange for Vote Crates.

## Here's how it works

1. Enter the command `/vote` in the game.
2. You will receive a link to the vote pages in the chat.
3. Vote for the server on the linked pages.
4. You will automatically receive **Votecoins** credited.

## Reward

Every vote gives you **Votecoins**. At the crate area (distributor) at spawn, you exchange 1 Votecoin for a **Vote Crate**, which contains various useful items and Pounds.
